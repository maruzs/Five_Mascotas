# ⚡ Animaciones y Motion (Framer Motion / Motion.dev)

Fórmulas matemáticas de resortes (spring physics), transiciones de entrada/salida y micro-interacciones.
Prohibido el uso de `transition: all 0.3s ease-in-out` genérico. Todos los componentes aquí utilizan curvas de Bézier cúbicas precisas y amortiguación elástica.
