# 📦 Componentes de UI (Filosofía shadcn/ui)

Los componentes en este directorio están desacoplados de frameworks pesados:
- Escritos en **React + TypeScript + Tailwind CSS**.
- Totalmente accesibles (WAI-ARIA).
- Cero librerías externas superfluas; solo usan `clsx` y `tailwind-merge` para combinar clases.
