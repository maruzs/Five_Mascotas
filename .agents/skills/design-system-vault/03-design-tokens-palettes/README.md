# 🎨 Tokens de Diseño y Paletas

Variables CSS y configuraciones de `tailwind.config.js` organizadas por tipología de software:
- **Dark Tech / Minimalist**: Basado en Linear, Vercel y Raycast.
- **Fintech / Trust**: Basado en Stripe y Mercury.
- **Editorial / Creative**: Tipografías Serif de alto contraste con fondos off-white.
